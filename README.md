# Saradha — Personal Developer Portfolio

## Features

- Responsive layout for mobile, tablet, and desktop
- Mobile navigation with accessible menu state
- Light and dark color themes
- Rotating typing effect in the hero
- Scroll-triggered reveal animations
- Project cards with technology tags and project links
- Accessible contact form UI with demo submission feedback
- Semantic HTML and keyboard-friendly controls

## Tech Stack

- HTML5
- CSS3 with custom properties, Grid, Flexbox, and responsive media queries
- Vanilla JavaScript
- [Lucide](https://lucide.dev/) icons
- Google Fonts: Manrope and DM Mono

## Setup

No build step is required.

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the folder with any local static server.
3. Replace placeholder project links, resume link, social links, and profile artwork with your own details.
